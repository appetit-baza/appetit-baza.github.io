Курьеры

Ставка курьера: 140 ₽ в час — задана бухгалтерией, изменить нельзя.

В Челябинске почасовую оплату выдают 2 раза в месяц по iiko — здесь вносится только оплата за заказы: впишите количество заказов и сумму из курьерской программы. При необходимости можно нажать «Посчитать по километрам» у курьера.

ФИОСПоЗа часыЗаказовЗа заказыИтогоИзъятие

«За часы» считается по времени × ставку, копейки отбрасываются. Вручную её не вписать — укажите время «С» и «По». «Изъятие сделано» — выплата из кассы с изъятием; «Изъятие не сделано» — выдали из сейфа без изъятия; «Изъятие частично» — часть с изъятием, остальное из сейфа (впишите, сколько с изъятием). Выберите в списке у курьера.
